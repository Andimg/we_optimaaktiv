# Wien Energie - Optima Aktiv
These values can be used for calculating energy cost.

## Strom
Monthly electricity prices [euro cent/kWh] according to Wien Energie's Strom Optima Aktiv plan.\
Data is stored in a csv file using `Year,Month,100% Oeko,Sonnenmix,Basismix` for Vienna as well as Lower Austria & Burgenland.\
Current pricing can be found here: https://www.wienenergie.at/privat/produkte/strom/optima-aktiv/

Direct links:
* [Informations- und Preisblatt Wien (Strom)](https://dokumente.wienenergie.at/link/sopta_0001-w/)
* [Informations- und Preisblatt Niederösterreich und Burgenland (Strom)](https://dokumente.wienenergie.at/link/sopta_0001-noe/)
> [!NOTE]
>***100 % Öko:*** Der Strom wird zu 100 % aus erneuerbaren Energiequellen wie Wasser, Sonne und Wind erzeugt.\
>***Sonnenmix:*** Der Strom wird zu 100 % aus erneuerbaren Energiequellen erzeugt, mindestens 30 % davon aus Sonnenenergie. Den Sonnenmix gibt es für einen kleinen Aufpreis im Vergleich zu 100 % Öko.\
>***Basismix:*** Der Strom wird aus erneuerbaren Energiequellen und zu einem kleinen Teil mit Erdgas erzeugt. Der Basismix kostet etwas weniger als 100 % Öko.
## Erdgas
Monthly natural gas prices [euro cent/kWh] according to Wien Energie's Erdgas Optima Aktiv Website: https://www.wienenergie.at/privat/produkte/erdgas/optima-aktiv/. \
Data is stored in a csv file using `Year,Month,100% Erdgas,Biogas-Anteil` for Vienna as well as Lower Austria & Burgenland.

Direct links:
* [Informations- und Preisblatt Wien (Erdgas)](https://dokumente.wienenergie.at/link/geopta__01-w/)
* [Informations- und Preisblatt Niederösterreich (Erdgas)](https://dokumente.wienenergie.at/link/geopta__01-n/)
> [!NOTE]
>***100 % Erdgas:*** Das Gas besteht zu 100 % aus Erdgas.\
>***Biogas-Anteil:*** Das Gas besteht aus 95 % Erdgas sowie 5 % Biogas. Den Biogas-Anteil gibt es für einen kleinen Aufpreis im Vergleich zu 100 % Erdgas.
